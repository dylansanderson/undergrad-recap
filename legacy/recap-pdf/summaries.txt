COURSE SUMMARY · CSU FULLERTON
CPSC 332 - File Structures & Database Systems
Semester Fall 2020 (fully online)
Instructor Kyoung Seop Shin
Textbook Fundamentals of Database Systems, 7e - Elmasri & Navathe
Tools Microsoft SQL Server, T-SQL, PowerShell
What this course is about
How data is modeled, stored and queried. The course goes from designing a database on paper (Entity-
Relationship diagrams), to turning that design into relational tables with primary/foreign keys, to removing
redundancy with normalization (1NF-3NF, functional dependencies), to writing SQL queries. It finishes with
how a DBMS actually stores data on disk: file structures, indexing, hashing, query optimization and
transactions.
Why you learned it
Almost every piece of software stores data somewhere. This course teaches you to design that storage so it
stays consistent, and to get answers out of it efficiently. For a computer engineer it's the bridge between
programming and real applications (web backends, logging systems, analytics).
The work you did
Homework 1: PowerShell script (Company.ps1) that builds and populates the textbook's 6-table COMPANY
database in SQL Server.
Homework 2: SQL queries, e.g. finding every student's 'classmates' using self-joins.
Homework 4: normalization exercises (Ch. 14) - find keys from functional dependencies, decompose into
2NF/3NF.
Scripts: a department-statistics report (SUM/AVG/COUNT with joins) exported to CSV from PowerShell; a
recursive tree table with a breadth-first-search stored procedure (usp_BFS) using cursors.
Two research-paper reviews: 'Weaving Relations for Cache Performance' (the PAX storage model) and
Google's 'Bigtable' distributed storage system.
Key concepts to re-learn
ER modeling -> relational schema mapping
Primary / foreign keys and referential integrity
Functional dependencies, keys, normal forms
(1NF, 2NF, 3NF, BCNF)
Relational algebra and SQL: SELECT/JOIN/GROUP
BY/HAVING/subqueries
Stored procedures, cursors, recursive data (trees)
in SQL
Row vs column storage, indexing, hashing, cache
behavior
Transactions and query optimization (concepts)
How it applies in the real world
Every web/mobile app backend (user accounts, orders, inventory) runs on these ideas - PostgreSQL, MySQL,
SQL Server.
Normalization prevents bugs where the same fact is stored twice and gets out of sync.
SQL reporting + scripting (like your PowerShell -> CSV report) is everyday work in IT, data analysis and
DevOps.
The Bigtable/PAX papers explain why modern analytics systems (BigQuery, Snowflake, Parquet files) store
data by column.
Where to start in this folder
Homework\scripts & data - all .sql and .ps1 files you can re-run against SQL Server
Homework\papers - your two paper reviews
Lecture Notes - Chapter 2 slides + the PAX paper

##### CPSC-351 Operating Systems_summary.pdf
COURSE SUMMARY · CSU FULLERTON
CPSC 351 - Operating Systems Concepts
Semester Fall 2019
Instructor Prof. Thomas L. Bettens
Textbook Operating System Concepts, 10e - Silberschatz, Galvin & Gagne
Tools C / C++ on Linux, POSIX threads (pthreads)
What this course is about
What an operating system does and how it does it: managing processes and threads, scheduling the CPU,
synchronizing concurrent code, managing memory (paging, virtual memory) and handling I/O. The
programming assignments are in C/C++ and use real OS APIs like fork() and pthreads.
Why you learned it
Every program you write runs on top of an OS. Knowing how processes, threads and memory work explains
performance problems, crashes and race conditions. For embedded and systems work (your 450 class and
beyond) it's essential background.
The work you did
Process homework: a 'time' utility that forks a child process, runs a command and reports elapsed time (Ex.
3.19).
Project 2: multithreaded sorting application - threads sort halves of an array and a merge thread combines
them (pthreads).
Synchronization homework: made a linked-list stack thread-safe with locks.
Virtual Memory Manager simulation analysis: explained why page faults dropped (539 -> 244) when
physical memory doubled.
Critical-thinking homework: researched and chose an inter-process communication (IPC) technique for a
scalable, mission-critical system.
Key concepts to re-learn
Processes vs threads; fork/exec/wait
CPU scheduling algorithms (FCFS, SJF, round-
robin, priority)
Race conditions, mutexes, semaphores, deadlock
Inter-process communication (pipes, shared
memory, message passing, sockets)
Paging, page tables, TLB, page faults, page
replacement
Virtual memory and address translation
File systems and I/O basics
How it applies in the real world
Multithreading is how modern apps use multi-core CPUs (games, servers, browsers).
Thread-safety bugs (race conditions, deadlocks) are some of the hardest bugs in industry - this class gives
you the vocabulary to find them.
Virtual memory/page faults explain why a computer slows down when RAM fills up.
IPC choices matter in robotics, cars, and microservice architectures where many processes must talk reliably.

Lab 4: flip-flops, registers and a simple accumulator-based processor.
Lab 5: finite state machines and controllers (4-bit counter, FSM in Vivado).

Lab 5: pipelining the Small16 processor (control_stage2/3).
Lab 6: hazard support in the pipelined Small16 (forwarding/stalling).
Homework: CPI and pipeline-hazard calculations for a 5-stage pipeline benchmark; hand-written machine-
code programs (e.g. squaring array values).

##### EGCP-447 Cyber-Physical Systems Security_summary.pdf

EGCP 447 - Introduction to Cyber-Physical Systems
(Hardware) Security
Semester Fall 2021
Instructor Dr. Jaya Dofe
Tools VHDL, Xilinx Vivado
Term paper team Alec Battisti, Brendan Grier
What this course is about
Security from the hardware up. Software security assumes the chip is trustworthy - this course asks what
happens when it isn't. Topics include hardware Trojans (malicious circuit modifications with a rare trigger and a
payload), counterfeit chip detection, logic locking, IC camouflaging, split manufacturing, side-channel attacks
(leaking secrets through power or timing), fault testing, and IoT security.
Why you learned it
Chips are designed in one place and manufactured overseas by third parties, so the supply chain is an attack
surface. As a computer engineer who designs hardware (281/381/446), this course teaches you how hardware
can be attacked and defended.
The work you did
Homework 1: fault sites and test vectors for a small circuit (testing/fault coverage).
In-class assignments: designing a hardware Trojan into a given circuit (rare trigger condition + payload).
Programming Assignment 2: inserted and detected a hardware Trojan in the ISCAS C17 benchmark circuit
in VHDL (C17_original vs C17_HT, counter-based trigger).
Project: (7,4) Hamming encoder/decoder in VHDL (error detection/correction).
FPGA labs: half/full adder, full subtractor, 8-bit up/down counter.
Term paper + presentation: 'Hardware Trojans in IoT Devices'.
Key concepts to re-learn
Hardware Trojans: trigger, payload, combinational
vs sequential
Threat model of the IC supply chain
Counterfeit detection and avoidance
Logic locking, IC camouflaging, split
manufacturing
Side-channel attacks (power, timing, EM)
Fault models and test vectors
Error-correcting codes (Hamming)
IoT security challenges
Physical unclonable functions / true random
numbers (Flash memory paper)
How it applies in the real world
Defense and aerospace agencies require trusted foundries because of hardware Trojan risk.
Side-channel attacks have broken real smart cards, crypto wallets and car key fobs.
Hamming/ECC codes protect RAM in servers (ECC memory), SSDs and satellites.
With ~75 billion IoT devices, cheap insecure hardware is a major real-world attack vector (e.g. the Mirai

COURSE SUMMARY · CSU FULLERTON
EGEE 203 - Electric Circuits (with 203L lab)
Semester Fall 2019 (quiz set F19); lab 203L
Instructor Dr. Fleur T. Tehrani (lecture); Prof. M. Hilfi (lab)
Textbook Engineering Circuit Analysis, 8e - Hayt, Kemmerly & Durbin (in Reference)
Tools Multisim, oscilloscope
What this course is about
The foundation of all electrical engineering. You learn to analyze circuits made of resistors, capacitors,
inductors and sources: Ohm's and Kirchhoff's laws, nodal and mesh analysis, superposition, Thevenin/Norton
equivalents, transient (RC/RL) responses, and AC steady-state analysis with phasors, impedance, AC power and
three-phase circuits.
Why you learned it
Every electronic device is a circuit. This is the prerequisite for electronics (303), digital electronics (441) and any
hardware work. Being able to simplify a circuit to its Thevenin equivalent is a skill you use for your whole
career.
The work you did
Weekly quizzes (Q3-Q11) and midterm - solutions kept for Fall 2019 plus a Spring 2018 practice set.
Chapter 3 homework (nodal analysis).
203L Experiment 1 and Lab 2: using the oscilloscope and Lissajous patterns to compare frequency and
phase (Multisim).
Experiment 6: steady-state sinusoidal behavior of RLC circuits.
Lab 8: superposition and Thevenin's theorem in AC networks.
Thevenin method cheat sheet (Thevenin Chart Outline).
Key concepts to re-learn
Ohm's law, KVL, KCL
Series/parallel reduction, voltage & current
division
Nodal and mesh analysis
Superposition, source transformation, Thevenin &
Norton
Capacitors, inductors; RC/RL transients and time
constants
Phasors, impedance, AC steady-state
Average/complex power, RMS, power factor
Three-phase (Y and Delta) circuits
How it applies in the real world
Thevenin equivalents are how engineers model batteries, sensors and amplifier inputs/outputs.
RC time constants set delays, filters and debounce circuits (see 446's debouncer).
AC/phasor analysis and three-phase power are how the power grid and motors work.
Oscilloscope skills are used in every hardware lab and debugging session.
Where to start in this folder
Exams & Quizzes - full quiz/midterm solutions (best practice material)
Lecture Notes - Thevenin method chart
Labs - 203L reports
Reference - Hayt textbook

##### EGEE-303 Electronics_summary.pdf
COURSE SUMMARY · CSU FULLERTON
EGEE 303 - Electronics
Semester Spring 2020
Instructor Dr. Hassan H. Hashemi
Textbook Microelectronic Circuits, 8e - Sedra & Smith
Companion lab EGEE 303L
What this course is about
Circuits built from semiconductor devices. It covers diodes and diode circuits, field-effect transistors
(MOSFETs/FETs) and bipolar junction transistors (BJTs): how to bias them, use them as amplifiers (small-signal
models), analyze amplifier frequency response, and build circuits with operational amplifiers (op amps).
Why you learned it
Transistors are the building block of all electronics, analog and digital. This course connects circuit theory (203)
to real devices, and leads into 441's CMOS digital electronics.
The work you did
Homework sets 1-6 (diodes, FETs, BJTs, amplifiers).
Exam 2 and final exam (open notes).
Project / direct assessment: diode load-line analysis (find IDQ, VDQ from a characteristic curve) and solving
a non-homogeneous differential equation for a circuit.
Lecture notes: FETs (91 pages), BJT small-signal and frequency response (65 pages), op amps (22 pages).
Key concepts to re-learn
Diode models, load lines, rectifiers
MOSFET/JFET operation and DC biasing
BJT operation, biasing, beta
Small-signal models and amplifier gain
Amplifier frequency response (Bode plots, -3 dB
points)
Op amps: inverting/non-inverting, ideal
assumptions
How it applies in the real world
Every audio amplifier, sensor interface and power supply uses these devices.
Op amps condition sensor signals before an ADC (e.g. ECGs, strain gauges, microphones).
Transistor switches drive motors, relays and LEDs from microcontroller pins (450).
MOSFET understanding leads straight into chip design (441).
Where to start in this folder
Lecture Notes - the three big lecture-note PDFs (FET, BJT, Op Amps) are the course in one place
Homework - your HW solutions
Exams & Quizzes - Exam 2 and final

##### EGEE-303L Electronics Lab_summary.pdf
COURSE SUMMARY · CSU FULLERTON
EGEE 303L - Electronics Laboratory
Semester Fall 2020 (virtual, via Zoom)
Instructor Prof. Jim Yu
Tools NI Multisim (installer in Coursework\_Software)
Corequisite EGEE 303 Electronics
What this course is about
The hands-on (simulated, since it was online) companion to 303. You build and measure diode, BJT, FET and
op-amp circuits in Multisim and write formal engineering lab reports. Experiments go from impedance
measurement and grounding safety, to diode power supplies, clippers and clampers, to transistor switches,
bias circuits and constant-current sources.
Why you learned it
It turns textbook equations into measurements and teaches you to write formal technical reports. The course
also partially fulfills the engineering writing requirement.
The work you did
Lab 1: review of basic concepts, impedance measurements and safety ground.
Lab 2A/2B: diode characteristics; AC-to-DC conversion with half/full-wave rectifiers and a Zener regulator.
Lab 3: clippers and clampers.
Lab 4: BJT as a switch.
Lab 5: BJT collector curves (Ic vs Vce).
Lab 7: linear-region constant current source.
Lab 8: voltage-divider bias with emitter feedback (beta-independent design).
Weekly quizzes and a final (diode circuits, constant-current design).
Key concepts to re-learn
Measuring impedance and grounding
Diode I-V curve, rectifiers, ripple, Zener regulation
Clipping and clamping circuits
BJT regions: cutoff, active, saturation
Biasing for stable operating points (Q-point)
Current sources and current mirrors
Formal lab report writing
How it applies in the real world
Every phone charger and power adapter uses rectifiers and regulators like Lab 2.
Transistor switches let microcontrollers drive relays and motors.
Beta-independent biasing is how real amplifiers stay stable across temperature and part variation.
Clear lab reports are how engineers document test results in industry.
Where to start in this folder
Labs - handouts (EGEE303L_...) and your reports; Multisim .ms14 files
Exams & Quizzes - quizzes and final

##### EGEE-323 Probability & Random Variables_summary.pdf
COURSE SUMMARY · CSU FULLERTON
EGEE 323 - Engineering Probability & Random
Variables
Semester Spring 2020
Folder contents Lecture outlines (Ch. 1-4), study guides
Style Engineering-oriented (signals, noise, measurement)
What this course is about
Probability tools for engineers. Starting from set theory and the axioms of probability, the course covers
conditional probability, independence, combined experiments and Bernoulli trials. It then introduces random
variables with distribution and density functions, common distributions (Gaussian, uniform, exponential,
Rayleigh, binomial, Poisson), expectation and moments (mean, variance, skew), and multiple random variables
with joint and conditional densities.
Why you learned it
Real engineering signals are noisy and real systems fail randomly. This course gives you the math to model
noise, reliability and uncertainty. It's needed for communications, signal processing, machine learning and
quality testing.
The work you did
Lecture outlines 1-16 covering Chapters 1-4.
Study guides for midterm 2 and the final.
Midterm review solutions.
Key concepts to re-learn
Sample spaces, events, axioms of probability
Joint and conditional probability, Bayes' rule
Statistical independence
Permutations, combinations, Bernoulli trials
Random variables; CDF and PDF; delta functions
for discrete RVs
Gaussian, uniform, exponential, Rayleigh,
binomial, Poisson
Expected value, variance, moments
Joint/conditional distributions of multiple random
variables
How it applies in the real world
Thermal noise in circuits and radio signals is Gaussian; signal fading is Rayleigh.
Poisson models network packet arrivals and server load.
Bayes' rule underlies spam filters, medical tests and machine learning.
Reliability engineering (mean time to failure) uses exponential distributions.
Where to start in this folder
Lecture Notes - numbered outlines in order (02 ... 16); very concise review sheets
Exams & Quizzes - study guides list exactly which topics matter

##### EGEE-401 Engineering Economics_summary.pdf
COURSE SUMMARY · CSU FULLERTON
EGEE/EGCP 401 - Engineering Economics &
Professionalism
Semesters Fall 2019 (EGEE 401, James Garner) and Fall 2021 (EGCP 401)
Textbook Engineering Economic Analysis, 14e - Newnan (in Reference)
Tools Excel / spreadsheets, interest tables
What this course is about
How engineers make money decisions and ethical decisions. The economics half covers the time value of
money: interest (simple, compound, nominal vs effective), cash-flow diagrams, present worth, annual worth
(EUAW), rate of return, depreciation and after-tax analysis, used to compare engineering alternatives. The
professionalism half covers engineering ethics through famous case studies.
Why you learned it
Engineers constantly have to justify designs in dollars: buy vs lease, repair vs replace, which project is worth
funding. Ethics matters because engineering failures hurt people. This is also a general-education (social
science) course.
The work you did
Homework: cash-flow diagrams, compound interest and present/future-worth problems (e.g. 'should the
firm sell the land?').
Quizzes and exams with hand calculations, e.g. finding the building height that minimizes cost.
Ethics case-study project (Fall 2021): the 2007 I-35W bridge collapse in Minneapolis.
Group project: economic analysis of a solar farm proposal for a DOE green-energy grant.
Famous ethics case group presentation (Fall 2019).
Key concepts to re-learn
Cash-flow diagrams
Simple vs compound interest; nominal vs effective
rates
Interest factors (P/F, F/P, A/P, P/A, gradients)
Present worth, annual worth (EUAW), future worth
Rate of return / IRR, payback
Depreciation and after-tax cash flows
Engineering ethics, codes of conduct, case studies
How it applies in the real world
Deciding whether a solar installation, new machine or software license pays off is exactly this math.
Excel's PV, FV, PMT, RATE and IRR functions are these formulas - used in finance, project management and
personal loans/mortgages.
Ethics failures like the I-35W bridge and Challenger shape engineering codes and regulations.
Where to start in this folder
Reference - Newnan textbook, compound interest tables, tax template
Exams & Quizzes - study guide for the final lists the key problems
Projects - bridge ethics case study, solar farm project

##### MATH-250B Differential Equations & Linear Algebra_summary.pdf
COURSE SUMMARY · CSU FULLERTON
MATH 250B - Introduction to Linear Algebra and
Differential Equations
Semester Fall 2019
Instructor Chris Lyons
Coverage Book Ch. 1-9: first-order ODEs -> matrices -> vector spaces -> higher-order & systems of
ODEs
What this course is about
Two big branches of applied math that come together at the end. First, ordinary differential equations: slope
fields, separable and linear first-order equations, and modeling physical situations. Second, linear algebra:
matrices, systems of equations, determinants, vector spaces, bases and dimension, inner product spaces, linear
transformations and eigenvalues. Finally, linear algebra is used to solve higher-order linear ODEs and systems
of first-order ODEs.
Why you learned it
It's the math behind circuits (203: RC/RLC circuits are differential equations), signals and systems (371:
Laplace/Z transforms solve them), control, graphics and machine learning (matrices everywhere). It's a
prerequisite for EGCP 371.
The work you did
13 homework sets (with solutions kept).
4 quizzes, 3 exams and a final, with solutions and the instructor's exam-information sheets.
Lecture slides by section (1.2-1.7, 2.3, 2.6, Ch. 3, 4.2, 4.6, Ch. 5).
Key concepts to re-learn
Slope fields and qualitative behavior of ODEs
Separable and linear first-order ODEs; modeling
(growth, mixing, circuits)
Matrix algebra, row reduction, inverses
Determinants
Vector spaces, subspaces, span, linear
independence, bases, dimension
Inner product spaces, orthogonality
Linear transformations, eigenvalues/eigenvectors
Higher-order linear ODEs; systems of ODEs
How it applies in the real world
RLC circuits, spring-mass systems and motor dynamics are all second-order ODEs.
Eigenvalues decide stability in control systems and vibration analysis (bridges, aircraft).
3D graphics, robotics (your 471 arm's kinematics) and machine learning are built on matrices and vector
spaces.
Google's original PageRank was an eigenvector computation.
